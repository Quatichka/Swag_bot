# SWAG Studio — бот для приёма заказов

Telegram-бот для студии [@swagdsgn](https://t.me/swagdsgn): клиент проходит короткую анкету,
заказ сохраняется в базу и сразу прилетает админам с кнопками управления.
Каждый экран бота сопровождается своей картинкой из папки `images/`.

## Что умеет

**Клиент**
- `🛒 Сделать заказ`: 5 шагов (услуга → описание → референсы → сроки → бюджет), потом проверка и отправка
- референсы: фото, альбомы, видео, файлы и ссылки
- `📦 Мои заказы`: история и статусы
- `❓ Задать вопрос`: вопрос уходит админам, ответ приходит в бот
- `💼 Услуги и цены`, ссылка на канал-портфолио и на менеджера
- уведомления с картинкой, когда заказ взяли в работу, выполнили или отклонили

**Админ**
- карточка заказа с вложениями и кнопками `✅ Принять` / `❌ Отклонить` / `🏁 Выполнен` / `💬 Написать клиенту`
- ответ клиенту любым сообщением: текст, фото, файл (бот перешлёт от имени студии)
- `/admin`: статистика и новые заказы, `/last`: последние 20, `/order_12`: открыть заказ

## Запуск

1. Создай бота у [@BotFather](https://t.me/BotFather) и скопируй токен.
2. Узнай свой Telegram ID, например у [@userinfobot](https://t.me/userinfobot).
3. Скопируй `.env.example` в `.env` и заполни `BOT_TOKEN` и `ADMIN_IDS`.
   - Каждый админ должен хотя бы раз нажать `/start` в боте, иначе Telegram не даст боту написать ему первым.
4. Установи зависимости и запусти (нужен Python 3.10+):

```bash
pip install -r requirements.txt
```

```bash
python bot.py
```

## Чат студии с темами

Бот может присылать заказы в рабочий чат, в отдельную тему.

1. Создай группу и включи в её настройках **Темы**.
2. Добавь туда бота. Добавлять должен админ из `ADMIN_IDS`, иначе бот сам выйдет из группы.
3. Сделай бота **администратором** с правом «Управление темами».
4. Бот сам создаст темы **📦 Заказы** и **❓ Вопросы**. Если не создал, отправь в группе `/setup`.

Дальше каждый новый заказ приходит в тему «Заказы» с кнопками `✅ Принять` / `❌ Отклонить`.
Как только кто-то нажмёт «Принять», клиенту в боте придёт уведомление «Заказ взят в работу»,
а в карточке появится, кто его взял. Нажимать кнопки может любой участник этого чата.

- `/setup` (только админы из `ADMIN_IDS`) пересоздаёт темы, например если их удалили.
- Если тему удалили или бота убрали из чата, заказы автоматически пойдут админам в личку.
- Без чата бот шлёт заказы в `ADMIN_CHAT_ID` из `.env`, а если его нет, то каждому админу в личку.

## Как настроить под себя

| Что | Где |
|---|---|
| Все тексты, описание услуг, цены | `app/texts.py` |
| Список услуг, вариантов сроков и бюджета | `app/keyboards.py` (`SERVICES`, `DEADLINES`, `BUDGETS`) |
| Картинки | `images/*.png` (1280×720, имя файла = ключ экрана) |
| Логотип на картинках | `assets/logo.png` (чёрный на белом) |
| Перерисовать картинки (другие тексты) | `generate_images.py` → `python generate_images.py` (нужен Pillow) |

Картинки можно заменить на свои: просто положи файл с тем же именем в `images/`.

| Файл | Экран |
|---|---|
| `welcome` | главное меню |
| `services` | услуги |
| `order_service` … `order_budget` | шаги 1–5 анкеты |
| `order_confirm` | проверка заказа |
| `order_success` | заказ отправлен |
| `my_orders` | мои заказы |
| `question` | вопрос студии |
| `status_accepted` / `status_done` / `status_rejected` | уведомления о статусе |

## Шрифты студии

В папке `fonts/` два своих шрифта, собранных по мотивам логотипа. Их можно установить на компьютер
(двойной клик → «Установить») и использовать в Photoshop, Figma и т.д.

- `SwagDisplay.ttf` — широкий жирный наклонный, как «SW». Только прописные, латиница + кириллица + цифры.
- `SwagScript.ttf` — тонкий рукописный, как «swag studio». Строчные, латиница + кириллица + цифры.

Шрифты генерируются кодом: буквы описаны в `fonts/build_display.py` и `fonts/build_script.py`.
Пересобрать после правок (нужен `pip install fonttools`):

```bash
python fonts/build_display.py
```

```bash
python fonts/build_script.py
```

## Структура

```
bot.py                 точка входа
app/config.py          настройки из .env
app/db.py              SQLite: заказы (data/orders.db)
app/screens.py         показ экранов «картинка + текст + кнопки»
app/keyboards.py       кнопки
app/texts.py           тексты
app/handlers/common.py меню, услуги, мои заказы, вопросы
app/handlers/order.py  анкета заказа и отправка админам
app/handlers/admin.py  статусы, ответы клиентам, /admin
app/handlers/group.py  чат студии: создание тем, /setup
app/routing.py         куда слать заказы и вопросы
```

Незаконченные анкеты хранятся в памяти: при перезапуске бота клиент, который был посреди
анкеты, просто начнёт заново. Сами заказы хранятся в базе и не пропадают.
