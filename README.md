# SWAG Studio — бот для приёма заказов

Telegram-бот для студии [@SSwag_studio](https://t.me/SSwag_studio): клиент проходит короткую анкету,
заказ сохраняется в базу и сразу прилетает админам с кнопками управления.
Каждый экран бота сопровождается своей картинкой из папки `images/`.

## Что умеет

**Клиент**
- `🛒 Сделать заказ`: 5 шагов (услуга → описание → референсы → сроки → бюджет), потом проверка и отправка
- референсы: фото, альбомы, видео, файлы и ссылки
- `📦 Мои заказы`: история и статусы
- `❓ Задать вопрос`: клиент пишет вопрос в бот, бот пересылает его админам в личку, ответ приходит в бот
- `💼 Услуги и цены`, ссылка на канал-портфолио и на менеджера
- уведомления с картинкой, когда заказ взяли в работу, выполнили или отклонили

**Админ**
- карточка заказа с вложениями и кнопками `✅ Принять` / `❌ Отклонить` / `🏁 Выполнен` / `💬 Написать клиенту`
- ответ клиенту любым сообщением: текст, фото, файл (бот перешлёт от имени студии)
- `/admin`: статистика и новые заказы, `/last`: последние 20, `/order_12`: открыть заказ

## Запуск

1. Создай бота у [@BotFather](https://t.me/BotFather) и скопируй токен.
2. Узнай свой Telegram ID, например у [@userinfobot](https://t.me/userinfobot).
3. Скопируй `.env.example` в `.env` и заполни `BOT_TOKEN` и `ADMIN_IDS`.
   - Каждый админ должен хотя бы раз нажать `/start` в боте, иначе Telegram не даст боту написать ему первым.
4. Установи зависимости и запусти (нужен Python 3.10+):

```bash
pip install -r requirements.txt
```

```bash
python bot.py
```

## Чат студии с темами

Бот может присылать заказы в рабочий чат — в ту тему, которую вы выберете.

1. Добавь бота в группу. Добавлять должен админ из `ADMIN_IDS`, иначе бот сам выйдет из группы.
2. Сделай бота **администратором**, чтобы он видел сообщения в группе.
3. Напиши `/setup` в той теме, куда присылать заказы. Бот ответит «Готово!» прямо в этой теме.

Дальше каждый новый заказ приходит туда с кнопками `✅ Принять` / `❌ Отклонить`.

- **Принять.** Кто первым нажал — тот исполнитель: в карточке появится «Взял: …», клиенту придёт
  уведомление «Заказ взят в работу». Дальше `🏁 Выполнен`, `🔄 Передать другому` и `💬 Написать клиенту`
  доступны только исполнителю — остальным бот ответит, что заказ уже взят.
- **Передать другому.** Исполнитель отдаёт заказ: он снова открыт, в чат приходит сообщение
  «Заказ снова открыт», и взять его может любой. Клиента это не беспокоит.
- **Отклонить — голосованием.** В группе заказ отклоняется, когда кнопку нажмут 5 разных человек
  (на кнопке виден счётчик, например `❌ Отклонить (2/5)`, а в карточке — кто проголосовал).
  Повторное нажатие отзывает голос. Число голосов меняется переменной `REJECT_VOTES`.
  В личке у админа заказ отклоняется сразу, без голосования.

- `/setup` в другой теме переносит заказы туда. В «Общем» или в группе без тем — заказы идут в весь чат.
- Настраивать бота (`/setup`) могут только админы из `ADMIN_IDS`.
- Если тему удалили или бота убрали из чата, заказы автоматически пойдут админам в личку.
- Без чата бот шлёт заказы в `ADMIN_CHAT_ID` из `.env`, а если его нет, то каждому админу в личку.
- Вопросы клиентов из «Задать вопрос» всегда приходят админам в личку.

## Шрифты студии

В папке `fonts/` шрифты для картинок бота. Их можно установить на компьютер
(двойной клик → «Установить») и использовать в Photoshop, Figma и т.д.

- `SwagDisplay.ttf` — широкий жирный наклонный, как «SW». Только прописные, латиница + кириллица + цифры.
- `Manrope.ttf` — [Manrope](https://fonts.google.com/specimen/Manrope), начертание Light, для подзаголовков;
  бесплатный, в том числе для коммерции (лицензия OFL, `fonts/Manrope-OFL.txt`).

SWAG Display генерируется кодом: буквы описаны в `fonts/build_display.py`.
Пересобрать после правок (нужен `pip install fonttools`):

```bash
python fonts/build_display.py
```

## Структура

```
bot.py                 точка входа
app/config.py          настройки из .env
app/db.py              SQLite: заказы (data/orders.db)
app/screens.py         показ экранов «картинка + текст + кнопки»
app/keyboards.py       кнопки
app/texts.py           тексты
app/handlers/common.py меню, услуги, мои заказы, вопросы
app/handlers/order.py  анкета заказа и отправка админам
app/handlers/admin.py  статусы, ответы клиентам, /admin
app/handlers/group.py  чат студии: /setup выбирает тему для заказов
app/routing.py         куда слать заказы и вопросы
```

Незаконченные анкеты хранятся в памяти: при перезапуске бота клиент, который был посреди
анкеты, просто начнёт заново. Сами заказы хранятся в базе и не пропадают.
